# Certifications: Which Ones Are Worth It?

> Certifications help most when they match the role and back up practical work, not replace it.

## When they help
- **Cloud**: entry-level cloud certificates (for example AWS Cloud Practitioner, Microsoft Azure Fundamentals, Google Cloud Digital Leader) show you know the basics. Associate-level ones carry more weight.
- **Networking and security**: CCNA, CompTIA Network+ and Security+ are widely recognised for network and security roles.
- **Data**: vendor certificates for tools like Power BI or Tableau help for BI and analyst roles.
- **Project and product**: Scrum or agile certificates can help for product and project roles.

## When they don't
A certificate without projects rarely gets you hired for developer roles. Employers prefer a GitHub project that uses the skill.

## Make them affordable
- Look for **free learning tracks and exam vouchers**: cloud providers, Cisco Networking Academy, and university partnerships often run them.
- Many certificates offer **student discounts**.
- Join study groups. Classmates preparing for the same exam keep you on schedule.

## How to show them
List the name, issuer and year on your CV and LinkedIn, and add a credential link. Mention what you built while studying for it.
