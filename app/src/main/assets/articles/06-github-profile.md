# Making Your GitHub Profile Work for You

> Pin your best repositories, write proper READMEs, and commit regularly.

## Why it matters
For developer roles, GitHub is often the first place a reviewer looks after your CV. A tidy profile shows you can finish and document work.

## Profile checklist
- A real name, photo and a one-line bio with your focus area.
- A **profile README** (a repo named exactly like your username) with a short intro, your stack and links.
- **Pin 4–6 repositories**: your best, not your newest.

## A good project README
1. What the project does, in one sentence.
2. A screenshot or short GIF.
3. Tech stack.
4. How to run it (copy-paste commands).
5. What you learned or would improve.

## Good habits
- Commit small, meaningful changes with clear messages: *Add login validation*, not *update*.
- Use `.gitignore`; **never commit passwords or API keys**. If you do, revoke the key immediately.
- Use branches and pull requests, even on solo projects. It shows you know team workflows.
- Contribute to open source: start with documentation fixes or issues labelled "good first issue".

## Avoid
Dozens of unfinished tutorial copies pinned at the top, empty READMEs, and repos that don't run.
