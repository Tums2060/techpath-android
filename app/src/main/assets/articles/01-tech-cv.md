# Writing a Tech CV That Gets Read

> A one- or two-page CV that shows what you built, what you used, and what changed because of it.

## What recruiters look for
Recruiters for internships and graduate roles usually spend under a minute on a first read. They look for evidence that you can learn quickly and ship working things. Make that evidence easy to find.

## Structure (in this order)
1. **Header**: name, phone, professional email, city, LinkedIn and GitHub links. No photo, ID number or date of birth needed.
2. **Summary (2 lines)**: who you are and what role you want. Example: *Third-year BICS student building Android and backend apps; looking for a software engineering attachment.*
3. **Skills**: group them: Languages, Frameworks, Tools, Cloud/Data. Only list what you could discuss in an interview.
4. **Projects**: your strongest section as a student. 2–4 projects, each with a one-line description, the tech used and one result.
5. **Experience**: attachments, part-time work, freelance, campus tech roles.
6. **Education**: university, course, expected graduation, relevant units, good grades.
7. **Certifications and achievements**: hackathons, competitions, certificates.

## Write strong bullet points
Use **action + what + how + result**:
- *Built a Kotlin app for booking campus labs, used by 120 students in its first month.*
- *Reduced API response time from 900 ms to 250 ms by adding Redis caching.*
- *Automated weekly sales reports with Python and pandas, saving the team 3 hours a week.*

Numbers help even when small: users, speed, time saved, marks.

## Tailor every application
Read the job description and mirror its key words where they are true for you. Many companies use applicant tracking systems that filter on keywords like "REST API", "SQL" or "React".

## Common mistakes
- Listing every technology you have ever touched.
- Long paragraphs instead of bullets.
- Broken or private GitHub links.
- Spelling errors: ask a friend to proofread.
- Saving as `.docx` with odd fonts. Export to **PDF** with a clear file name like `Jane_Wanjiru_CV.pdf`.
