# Portfolio Projects That Impress

> Build two or three real, finished projects that solve a problem you understand.

## Pick the right projects
- **Solve a real problem**: something for your campus, a family business, a chama, a church group. Real users make strong stories.
- **Match your target role**: Android roles want a published or installable app; data roles want a notebook plus a dashboard; backend roles want a deployed API with docs.
- **Go deep rather than wide**: one finished project with authentication, a database, tests and deployment beats five half-built clones.

## Project ideas by path
- **Mobile**: an offline-first expense tracker that syncs when online.
- **Backend**: a booking API with authentication, payments in sandbox mode and rate limiting.
- **Frontend**: an accessible, responsive dashboard for a public dataset.
- **Data**: analyse county-level open data and publish a Power BI or Streamlit dashboard.
- **Cyber security**: a home lab with write-ups of CTF challenges you solved.
- **AI**: a retrieval-augmented chatbot over your course notes, with an honest note on its limitations.

## Finish like a professional
- Deploy it (a free tier is fine) or provide an APK.
- Write the README, add screenshots and a short demo video.
- Add a few tests and basic error handling.
- Note what you would do next. It shows you can judge your own work.
